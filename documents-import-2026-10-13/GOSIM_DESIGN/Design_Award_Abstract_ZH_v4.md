# 观天识时，择机而动
**从天文观测智慧到自主智能体设计**  
*The Sky Is Not a Queue — An Astronomy-Inspired, Evidence-Grounded Autonomous Observer*

## 申报摘要（约 500 字）

天文学中的天空并非静态任务队列。观测窗口随着天体运动消失，月光和大气改变科学收益，焦面光纤的几何约束决定了哪些目标能够同时测量。DESI、PFS 已有成熟的自动规划、光纤配置和质量反馈体系。因此，我们提出的并不是用 LLM 取代观测自动化，而是下一层 Agent 工程问题：**如何把专业优化器、跨季节的价值判断和不断到来的运营信息，组织成可执行、可校准、可追溯的连续决策？**

长期优化本身不依赖大语言模型；LLM 的意义在于解释异常、含糊或变化中的非结构化信息。我们的答案是将天文学的观测逻辑组织为一套**分层规划与闭环控制架构**：`season.py` 为未来时段的稀缺观测机会赋予软价值权重，把长期规划压缩成实时决策可以消费的信息；`planner.py` 在物理可行域内联合选择指向、光纤分配、曝光时长和观测模式，以由粗到精的候选搜索平衡收益与计算成本；每次曝光后，`Planner.on_result()`、`bandfit.py` 和 `fault.py` 用实际命中与质量回执校准模型、更新指向和故障证据。对于复杂公告与值班日志，LLM 只是受契约约束的语义接口：结构、原文、时效和权限验证决定其输出能否进入运营状态，而不是让文本直接授权高代价行动。`walltime.py` 进一步把 CPU 与真实时间作为状态变量，动态调节搜索复杂度，并保留无模型的降级路径。

设计的美感在于各个模块拥有**清晰而有限的责任**：物理定义可能，规划决定值得，观测检验判断，证据约束权限。它不是一个会描述天文学的 Agent，而是一个其工程结构由天文学的时间观、物理约束和实证方法共同塑造的自主系统。

## 200 字精简版

DESI/PFS 已将巡天自动化发展得相当成熟；我们的目标不是重造调度器，而是进一步协调跨时间尺度的决策与不断变化的运营信息。天空不是任务队列：观测窗口不可逆，光纤几何限定行动，天气和仪器状态持续变化。我们将这些天文事实转化为 Agent 的工程结构：观测季层为未来机会定价，曝光层在物理可行域中联合优化指向、光纤、时长和模式；真实曝光回执持续校准质量、指向与故障证据。LLM 只承担有结构和时效校验的语言解释，不直接获得高代价行动权限；计算预算决定搜索深度，模型失效时仍可由规则闭环运行。**物理定义可能，规划决定值得，观测检验判断，证据约束权限。**

## 复现说明（报名表附注）

固定 Runner 15 原始代码及 `observer.project.json`，在 Python 3.10+ 上使用 `python3 -u agent.py` 入口；材料包包含 `smoke_local.py`，自动应用提交环境变量进行无模型的合成协议测试。已复现晴空 `observe` 和全天区降雨 `wait` 两个分支；完整比赛得分需在相同引擎、卡片和模型配置下由官方平台重评。本材料不把未启用的实验模块视作已验证贡献。

# Changes in v0.2.0

Independent successor to the exported Python Pro reference. Original implementations and official runner preserved. Standard-library dependencies and JSONL v4 action interface retained; additive PRO_* controls, sidecar and QA CLI introduced.

- Load fiber capacity/central cells and conservative full footprint queries; requery shifts and check emitted commands using learned offset geometry.
- Respect loaded exposure/wait declaration bounds, official actual clipping and full-interval target visibility.
- Retain request windows/thresholds; distinguish ordinary science legality from request credit; aggregate overlapping request reward by its completion condition.
- Separate best contribution, estimated raw factor and conservative required-state evidence; record public hits, invalidate official observe-index ranges and replay surviving evidence.
- Evaluate declared programs for leading candidates; add bounded public-model duration events and per-decision gain caching.
- Add CPU reserve, in-search deadlines/best-so-far fallback and correct selected-level timing attribution.
- Record every action/outcome with version/config/source/state IDs, estimated score components, uncertainty, alternatives, transitions and CPU/logging metrics.
- Add offline whole-log/per-step/streamed replay review; optional remote reviewer has bounded elapsed time/retries/size/in-flight and strict schema, no state authority.
- Missing advisory credentials now select rules only; optional existing night/fault advisory stages otherwise retained. Retry backoff/attempts share the remaining deadline.
- Add synthetic regression tests and isolated source-snapshot no-model local comparisons.

Performance acceptance is pending paired results. These entries describe implementation; they do not establish score gains. Current feature defaults may change after ablations. No new numerical parallelism, randomness, runtime packages or unmodeled observing overheads.
